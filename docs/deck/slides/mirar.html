Antes de la demo

Tres cosas para mirar mientras trabajan

1

Se reparten el trabajo.

Tres agentes salen a la vez. Nadie hace todo solo.

2

Se avisan entre ellos.

Uno encuentra algo que cambia el análisis de otro. Nadie se lo pidió.

3

Proponen y esperan.

Nadie llama a nadie. La escuela se queda quieta hasta que una persona decide.
